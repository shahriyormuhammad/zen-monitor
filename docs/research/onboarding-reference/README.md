## Выводы для нашего продукта

- Код из email полезен как понятный шаг подтверждения, но требует нормальной
  transactional-почты и DNS-настроек, иначе письма будут уходить в спам.
- Пароль не стоит превращать в отдельный квест: достаточно минимальной длины и
  подсказок, без жесткого требования спецсимволов/регистра на MVP.
- Первая синхронизация не должна блокировать вход в кабинет. Пользователя нужно
  пускать в продукт сразу, а прогресс показывать фоновым статусом.
- В промежуточных экранах лучше объяснять наш сервис и следующий полезный шаг,
  а не показывать внешние новости WB.
- Первый dashboard не должен быть перегруженной аналитической таблицей. Нужен
  стартовый экран с понятным состоянием: ключ, синхронизация, первые действия,
  помощь.
