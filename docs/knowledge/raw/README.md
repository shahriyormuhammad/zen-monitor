# Raw

Здесь лежат сырые источники: заметки со встреч, выдержки из чатов, ссылки на статьи, скриншоты, первичные исследования.

## Правила

- Один материал - один файл с понятным названием и датой, если это временной контекст.
- В начало файла добавлять коротко: откуда материал, дата, зачем сохранен.
- Если из материала принято решение, вынести результат в `decisions/`.
- Если материал стал постоянным знанием, перенести выжимку в `wiki/`.
- Не хранить секреты, токены, cookies, приватные ссылки и персональные данные.

## Мини-шаблон

```md
# Название

Дата: YYYY-MM-DD
Источник: ссылка или путь
Зачем сохранено: коротко

## Выжимка

## Сырой материал
```
