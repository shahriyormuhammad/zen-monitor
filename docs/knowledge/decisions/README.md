# Decisions

Здесь фиксируются решения, которые влияют на архитектуру, данные, продуктовые правила или эксплуатацию.

## Когда добавлять запись

- Меняется источник правды.
- Меняется финансовая формула.
- Добавляется новый контур данных или интеграции.
- Принимается решение, которое потом легко забыть или оспорить.
- Есть важный компромисс: быстро/надежно, просто/гибко, временно/постоянно.

## Шаблон

```md
# NNNN - Название решения
```
