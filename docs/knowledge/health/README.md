# Knowledge Health

Минимальная проверка проектной памяти:

```bash
npm run knowledge:health
```

## Что проверяет скрипт

- Наличие базовых файлов `docs/knowledge`.
- Наличие `## Источники` у wiki-страниц.
- Наличие обязательных разделов у decision records.
- Битые wiki-ссылки в double-bracket формате.

## Что проверять вручную

- Не устарела ли страница после изменения кода.
- Нет ли секретов, токенов, cookies и персональных данных.
- Не попал ли сырой чат в `wiki/` без выжимки.
- Есть ли ссылка на код, документ или decision record для важных правил.

## Правило конфликта

Если wiki противоречит коду, актуальным считается код и свежий decision record. После обнаружения конфликта надо обновить wiki или явно пометить страницу как устаревшую.
