# Проектная память Procifry

Это внутренняя память разработки и эксплуатации проекта. Она не является пользовательской памятью продукта и не хранит персональные сведения клиентов.

Цель: быстро восстанавливать контекст, не терять принятые решения и не размазывать важные правила по чатам.

## Как читать

1. [Карта проекта](wiki/project-map.md) - какие контуры есть и где искать правду.
2. [Себестоимость и юнит-экономика](wiki/costing-and-unit-economics.md) - текущий источник себестоимости и правила расчетов.
3. [Финансовые формулы](wiki/finance-formulas.md) - PnL, валовая прибыль, ДРР, CPO/CPS.
4. [Финансовый контур](wiki/finance-management.md) - счета, кассы, операции, ДДС, долги и план-факт.
5. [Источники данных Wildberries](wiki/wildberries-data-sources.md) - откуда берутся товары, заказы, продажи, склады и реклама.
6. [Agent API и согласования](wiki/agent-api-approvals.md) - как работают approval-required действия.
7. [Решения](decisions/README.md) - почему сделано именно так.
8. [Health-check](health/README.md) - как проверить, что память не разъехалась.

## Структура

- `raw/` - сырые заметки, материалы, расшифровки, внешние статьи.
- `wiki/` - вычищенные знания проекта: как сейчас работает система.
- `decisions/` - короткие записи архитектурных и продуктовых решений.
- `health/` - проверки актуальности и правила ухода за памятью.

## Правила

- Не складывать в `wiki/` сырой поток чата. Сначала выжимка, потом ссылка на источник.
- Для важного знания указывать `## Источники`.
- Если код и wiki противоречат друг другу, актуальным считается код и свежий decision record.
- Не хранить секреты, токены, cookies, приватные ключи, персональные данные пользователей.
- После значимых изменений обновлять только релевантную страницу, не все подряд.
- Перед завершением больших задач запускать `npm run knowledge:health`, если менялась проектная память.

## Что сюда писать

- Правила расчета себестоимости, PnL, складов, ДРР, налогов.
- Решения по архитектуре данных, таблицам, источникам правды.
- Эксплуатационные правила: deploy, smoke, backups, incident response.
- Нюансы интеграции Wildberries и Procifry Agent API.
- Известные риски и анти-паттерны проекта.

## Что сюда не писать

- Оперативные TODO на один день.
- Полные дампы логов без выжимки.
- Секреты и содержимое `.env`.
- Черновики, которые не влияют на дальнейшую работу.
