# Wiki

`wiki/` - очищенная проектная память. Здесь должны быть не мысли вслух, а текущие правила работы системы.

## Требования

- Каждая страница, кроме этого README, должна иметь раздел `## Источники`.
- Если знание спорное, указывать статус: `текущее`, `проверить`, `устарело`.
- Формулировать по-русски, коротко и прикладно.
- Не дублировать большие куски кода. Достаточно ссылки на файл и смысл.

## Шаблон страницы

```md
# Название

## Суть

## Как работает сейчас

## Правила изменения

## Риски

## Источники
```
